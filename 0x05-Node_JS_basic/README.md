## Introduction
This project is part of the ALX Backend JavaScript curriculum. It covers the basics of Node.js, including modules, file system operations, and HTTP servers.

## Getting Started
To get started with this project, clone the repository and install the necessary dependencies.

```bash
git clone https://github.com/Henry4593/alx-backend-javascript.git
cd alx-backend-javascript/0x05-Node_JS_basic
npm install
```

- `README.md`: Project documentation.
- `package.json`: Project metadata and dependencies.

## Scripts
The following scripts are available in the `package.json` file:

- `start`: Runs the application.
- `test`: Runs the test suite.

```json
"scripts": {
  "start": "node index.js",
  "test": "jest"
}
```

## Dependencies
The project relies on the following dependencies:

- `express`: Fast, unopinionated, minimalist web framework for Node.js.
- `jest`: JavaScript testing framework.

Install the dependencies using:

```bash
npm install
```
